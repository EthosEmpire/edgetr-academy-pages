Glossary term

Confluence

The situation where several independent tools or observations point to the same price area or conclusion.

An example is a horizontal support level that coincides with a rising trend line and a moving average. Analysts treat confluence as adding weight to a level, but it does not make any outcome certain. Tools built from the same price data, such as several momentum oscillators, are not independent and add little.
