Ethereum: An Overview

Ethereum is a public blockchain, launched in 2015, that runs programs called smart contracts. Its native asset is ether (ETH), which normally pays for each transaction on the network.

Why it matters

Ethereum is the network where most of the ideas beyond simple payments took shape: tokens, stablecoins, decentralised exchanges, lending protocols and NFTs. Many other blockchains copy its design or run its software. Understanding Ethereum in outline makes much of the wider crypto landscape easier to follow.

This page explains what Ethereum is and how it works. It does not assess ether as an asset.

How it works

Ethereum is a public blockchain that can run programs. Where Bitcoin mainly records transfers of one asset, Ethereum records the state of a shared computer: balances, and also the code and data of every program deployed to it.

Those programs are smart contracts. They run inside the Ethereum Virtual Machine (EVM), a standard environment that every node executes identically. If one node runs a contract and gets a result, every honest node running the same contract gets the same result.

The network’s native coin is ether (ETH). It has two jobs:

  • Paying for computation. Each transaction normally costs a fee in ether, measured through gas.
  • Securing the network. Validators lock up ether as a stake that they can lose for misbehaving. See proof of stake.

In plain words

Bitcoin resembles a calculator built for one job. Ethereum resembles a shared computer that anyone can load a program onto. Running a program costs a small fee for every step, so that nobody can clog the machine without paying.

Accounts and transactions

Ethereum keeps a balance for each account, in the way a bank ledger does. This is called the account model, and it differs from Bitcoin’s UTXO model.

A transaction on Ethereum can do one of three things:

Transaction What happens
Send ether A balance moves from one account to another
Call a contract A function in a deployed program runs and may change its data
Deploy a contract A new program is stored on the chain at a new address

Since the Merge, blocks have been produced at a steady rhythm of roughly one every 12 seconds.

Going deeper

From proof of work to proof of stake. Ethereum launched with mining, like Bitcoin. In September 2022 it replaced miners with validators, an event known as the Merge. The change cut the network’s electricity use sharply and changed how new ether is issued.

Ether has no fixed maximum supply. New ether is issued to validators as a reward. Since August 2021, part of every transaction fee, the base fee, is destroyed (“burned”). Whether the total supply grows or shrinks over a period depends on how those two flows compare, which depends on how busy the network is.

Scaling. The base chain processes a limited number of transactions, and fees rise when demand is high. Much activity has moved to Layer 2 networks, which process transactions separately and settle to Ethereum.

Upgrades and governance. Changes to Ethereum are proposed in public documents called Ethereum Improvement Proposals (EIPs) and adopted when the people running the software agree to upgrade. No single body can order a change.

EVM-compatible chains. Several independent blockchains run the same virtual machine. Contracts and wallets work on them in a similar way, but each has its own coin, its own validators and its own security.

One transaction, start to finishHypothetical illustration

Hypothetical numbers. Maya’s account holds 1.000 ETH. She sends 0.250 ETH to a friend, and the network fee is 0.001 ETH.

  • Her wallet signs the transaction with her private key and broadcasts it.
  • A validator includes it in a block. Other validators check it and attest that the block is valid.
  • Maya’s balance becomes 1.000 minus 0.250 minus 0.001 = 0.749 ETH.
  • Her friend’s balance rises by 0.250 ETH.

Of the 0.001 ETH fee, the base-fee portion is burned and the small remainder, the tip, goes to the validator.

What it does NOT mean

  • Ethereum is not a company. It is open-source software run by independent operators. Organisations support its development, but none owns the network.
  • Ether and Ethereum are not the same thing. Ethereum is the network. Ether is the asset used on it.
  • “Runs on Ethereum” is not an endorsement. Anyone can deploy a contract or a token, including fraudulent ones.
  • Proof of stake did not make fees low. The Merge changed how blocks are secured, not how many transactions fit in them.
  • A burn does not mean supply always falls. Issuance continues, and the net change depends on network activity.

Common misunderstandings

  1. Calling every token on Ethereum “Ethereum”. Tokens are separate assets issued by contracts. Only ether is native.
  2. Assuming a failed transaction is free. The network still charges for the computation that was carried out.
  3. Treating EVM-compatible chains as Ethereum. They share tools and address formats, not security or assets.
  4. Confusing the network with applications on it. A bug in one DeFi application is not a failure of Ethereum, and Ethereum’s soundness does not protect that application’s users.

Risks and limits

  • Smart contracts can contain bugs, and deployed code is hard or impossible to change.
  • Fees on the base chain can become high during busy periods.
  • Staked ether is exposed to penalties and to delays when withdrawing. See staking.
  • Upgrades are complex and carry technical risk.
  • Like any crypto asset, ether has a market price that can move sharply.

Key takeaway

Ethereum is a public blockchain that works as a shared computer: it runs smart contracts, charges for computation in its native coin ether, and has been secured by proof of stake since 2022. It is the base that much of the token and DeFi world is built on.
